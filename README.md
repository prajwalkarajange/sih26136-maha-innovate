# 🚀 MahaInnovate

### AI-Powered Startup-Friendly Government Innovation Procurement Platform

> **Connecting Government Problems with Innovative Startup Solutions.**

**Smart India Hackathon 2026 • Problem Statement: SIH26136 • Government of Maharashtra**

MahaInnovate is a full-stack AI platform that connects government departments with innovative startups through a structured workflow from **challenge → AI analysis → startup matching → proposal evaluation → pilot → procurement → scaling**.

---

## 💡 Why MahaInnovate?

Government departments have problems. Startups have innovative solutions.  
MahaInnovate creates a digital bridge using **AI-powered requirement analysis and semantic startup matching**.

### 🔄 Core Workflow

```text
Government Challenge
        ↓
AI Requirement Analysis
        ↓
Startup Matching & Ranking
        ↓
Eligibility Verification
        ↓
Proposal Evaluation
        ↓
Pilot + KPI Evaluation
        ↓
Procurement
        ↓
Scaling & Impact
```

---

## ✨ Key Features

- 🏛️ **Government Challenge Management**
- 🤖 **AI Requirement Analysis**
- 🔍 **Semantic Startup Matching**
- 📊 **AI-Assisted Ranking & Recommendations**
- 📄 **Proposal Submission & Evaluation**
- 🧪 **Pilot & KPI Management**
- 📝 **Procurement & Contract Tracking**
- 📈 **Scaling & Impact Monitoring**
- 🔐 **Role-Based Authentication**
- 📊 **Analytics Dashboard**

> **AI assists with analysis and recommendations; eligibility and final procurement decisions remain with authorized users and defined rules.**

---

## 🧠 AI Matching

```text
Requirement Analysis
        ↓
Embedding Generation
        ↓
Semantic Similarity
        ↓
Eligibility Rules
        ↓
Weighted Ranking
        ↓
Startup Recommendations
```

Uses **Google Gemini, Sentence Transformers, embeddings, semantic similarity, and rule-based eligibility checks**.

## 🛠️ Tech Stack

**Backend:** Java • Spring Boot • REST APIs • Spring Security • JWT  
**Database:** PostgreSQL • pgvector • JPA/Hibernate  
**AI/ML:** Google Gemini API • Python • FastAPI • Sentence Transformers  
**Tools:** Git • GitHub • Maven • Postman • Docker
